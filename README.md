# Learning Management System (LMS)

A full-stack Learning Management System application built with a Spring Boot backend and an HTML/JavaScript frontend.

## Features
* **Role-Based Dashboards**: Tailored views and controls for administrators, instructors, and students.
* **Course & Category Management**: Tools for creating, organizing, tracking, and reviewing courses and categories.
* **Enrollments & Payments**: Secure tracking of student course progress, enrollments, and payment processing.
* **Authentication**: Robust user registration, login workflows, and centralized exception handling.

## Tech Stack
* **Backend**: Java, Spring Boot, Spring Data JPA, Maven
* **Frontend**: HTML5, CSS3, JavaScript

## Project Structure
* `src/`: Contains the core backend Spring Boot application files, including controllers, services, repositories, models, DTOs, and configuration classes.
* `frontend/`: Contains the user interface files, HTML dashboards, stylesheets, and client-side JavaScript logic.
* `pom.xml`: Maven configuration file managing project dependencies.
